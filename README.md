# 塑料原料行情

手机优先的塑料原料行情网页，展示原油价格、塑料原料（期货 + 现货）、备货参考信号与行业资讯。

页面地址：https://zhuyilun520.github.io/plastic-quote/

## 页面内容

- **原油**：布伦特、WTI、上海原油 SC（实时价 + 涨跌 + 近 60 日走势）
- **塑料原料**：
  - PP 聚丙烯 / PE 聚乙烯 / PVC 聚氯乙烯：期货主力价（实时）+ 生意社现货价 + 基差
  - ABS / GPPS 聚苯乙烯：现货报价中位数（无期货合约）
  - 每个品种带 30/60/90 日走势图与近 90 日位置分位
- **备货参考**：价格分位、连涨连跌天数、1/7/30 日涨跌幅、原料/原油比价分位
- **原油 → 原料传导**：近 30 日涨跌幅对比、原料相对原油的比价位置
- **行业资讯**：塑料 / 原油 / 宏观三类，来自生意社与新浪财经

## 数据来源

| 数据 | 来源 | 说明 |
|---|---|---|
| 期货实时行情 | 新浪财经 | 主力连续合约，涨跌以昨结算价为基准 |
| 期货历史 K 线 | 新浪财经 | 保存最近 180 个交易日 |
| PP/PE/PVC 现货价 | 生意社现期表 | 每日更新 |
| 现货历史采样 | 生意社现期图 | 约 90 天，10 天一个采样点，逐日累积 |
| ABS/GPPS 现货 | 生意社报价中心 | 取最新日期报价中位数，非成交价 |
| 资讯 | 生意社商品动态、新浪财经 7x24 | 仅提取标题/时间/导语/原文链接 |

## 自动更新

GitHub Actions 每天三次（北京时间 07:00 / 12:00 / 17:30）运行 `scripts/fetch_data.py`，
抓取数据写入 `docs/data.json` 并自动提交，GitHub Pages 随之更新。

抓取失败时脚本会沿用上一版数据并在页面顶部显示警告，不会编造数字。

## 目录结构

```
docs/                  GitHub Pages 发布目录
  index.html           页面（单文件, 无外部依赖）
  data.json            数据（脚本生成, 勿手改）
scripts/
  fetch_data.py        抓取脚本（仅用 Python 标准库）
.github/workflows/
  update.yml           定时任务
```

## 本地运行

```bash
python scripts/fetch_data.py          # 抓取数据
cd docs && python -m http.server 8765 # 本地预览 http://127.0.0.1:8765
```
